1. 運営・企画

Operations / Planning

まず、何を本気で遊んでいるのか。

ティッシュ投げ選手権は、ニコニコ超会議のクリエイタークロスで「ぼくたち」が運営する参加型企画。 幕張メッセでティッシュを投げ、飛距離を競う。

Event

ニコニコ超会議とクリエイタークロス

ニコニコ超会議は、毎年幕張メッセで開催される、ネットとリアルの文化が交差する大型イベント。 クリエイタークロスは、個人やチームが自分たちの活動を展示、発表、販売できる場。

参加者がティッシュを1枚持ち、計測エリアへ向かって投げる。

02

落下地点までの飛距離を計測。記録として残す。

03

競う

会場ランキングで順位を確認。誰でもその場で挑戦できる。

Team

運営「ぼくたち」

本気で遊ぶことを目的とする男たち。クリエイタークロスでは「みんなを主役に」というコンセプトで、自分たちは競技スタッフに徹する。

こみこみ

ゆうすけ

ぼくたちのカメラマン。いつもニコニコしていて、動画撮影と編集に情熱を持つ。

Why System

なぜシステムが必要になったのか。

参加者が増えるほど、記録入力、ランキング更新、集計、表示、振り返りが重くなる。 現場の熱量を落とさず、参加者の体験を広げるために、運営システムが必要になった。

Issue 01

記録入力が詰まる

参加者が増えると、スタッフの入力作業と確認作業がボトルネックになる。

Issue 02

ランキング更新が重い

会場で盛り上がる瞬間を逃さないためには、記録反映の即時性が必要になる。

Issue 03

振り返りが難しい

記録を残すだけでなく、次回の運営改善や競技分析に使える形で蓄積したい。

2. 今のシステム

Current System

企画が、少しずつ仕組みになってきた。

最初は記録入力とランキング表示から始まり、現在はWebアプリによる現場運営へ広がっている。

V1

記録入力の開始

スタッフが記録をスプレッドシートへ入力。紙や口頭の記録を、まずデータとして残す段階。

現場スタッフ 記録入力
Google Sheets 記録表
運営確認 記録一覧
V2

ランキング表示

スプレッドシートの記録をLooker Studioで可視化。会場でランキングを見せる運営へ拡張。

現場スタッフ 記録入力
Google Sheets 記録DB
Looker Studio 集計・可視化
PC表示 ランキング
V3

Webアプリ化

スマホブラウザで記録入力、PCブラウザでランキング表示。現場運営に合わせた専用UIへ移行。

スマホブラウザ 記録入力UI
Webアプリ 運営システム
アプリ内データ 記録保存
PCブラウザ ランキング表示

現在できていること

  • スマホブラウザからの記録入力
  • PCブラウザでのランキング表示
  • 現場運営向けの専用UI化

現在残っている課題

  • 計測値の自動連携
  • 記録データの長期蓄積と分析
  • 参加者体験と運営効率の両立
3. 今後のシステム

Future System

これから、競技体験そのものを拡張する。

目指すのは、単に記録を取るだけの仕組みではない。計測、記録、分析、観戦、運営をひとつの流れにすること。

Next 01

自動計測

距離計測器の通信を受け取り、自動でデータベースに記録。

Next 02

競技データ分析

風、湿度、フォームを集め、遠くに飛ぶ条件を分析。

Next 03

マイアカウント

競技者ごとの個人記録、参加履歴、成長を可視化。

Next 04

現場運営UI

記録入力、ランキング更新、表示管理を現場向けに最適化。
