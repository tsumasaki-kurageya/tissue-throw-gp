# GitHub Pages実装計画

## 本ドキュメントの目的

GitHub Pagesの設計と実装方針をまとめる。  
最初の公開版は、本ドキュメントの内容をもとに段階的に実装する。  

## Pages作成の目的

このリポジトリの目的は、ニコニコ超会議 クリエイタークロスに出展している「ティッシュ投げ選手権」のDX推進。  
GitHub Pagesでは、ティッシュ投げ選手権の運営とDX推進の大義を伝え、技術協力してくれる開発者を募る。  

## 想定読者

- 技術協力してくれる開発者
- イベント運営のDXに興味がある開発者
- 計測、データ分析、Webアプリ、マイコン連携に興味がある開発者

## 読後のゴール

読んだ人が、ティッシュ投げ選手権のDXに興味を持ち、開発に参加する。  
そのために、以下を伝える。  

- 何の競技か
- なぜDXが必要か
- これまで何を作ってきたか
- これから何を作りたいか
- どの技術領域で協力できるか

## 初回公開版のスコープ

最初の公開版では、現在のアイデア・ドラフト章の内容をページ化する。  
細かい実装履歴や技術仕様は後続版で拡張する。

### 3. ティッシュ投げ選手権とは

ティッシュ投げ選手権は、クリエイタークロスで「ぼくたち」というチームが運営する参加型企画。  

幕張メッセでティッシュを投げ、その飛距離を競う競技。  
誰でも参加できる単純なルールながら、投げ方、力加減、紙の扱い、会場環境によって記録が変わる。  
そのゆるさと奥深さを、イベント会場で楽しめる形にした企画。

### 5. システムの生い立ち

ティッシュ投げ選手権の運営システムは、開催ごとに少しずつ進化してきた。  
最初は記録入力とランキング表示を中心に、現在はWebアプリによる現場運営へ広がっている。  

- V1からV2: スプレッドシートに記録を入力し、Looker Studioでランキング表示
- V3: Webアプリを構築し、スマホブラウザで記録入力、PCブラウザでランキング表示

### 6. DXが目指す世界

プロジェクトが目指すのは、単に記録を取るだけの仕組みではない。  
競技、運営、観戦、分析をつなぎ、ティッシュ投げ選手権そのものを拡張するシステム。  

- [問題1] 計測後にシステムに入力する手間がかかる
  距離計測器の通信を受け取り、自動でデータベースに記録できるようにする  
- [問題2] どんな条件で投げたら遠くに飛ぶのか、誰もわからない
  風、湿度、フォームなど、多角的なデータ分析で競技レベルを底上げ  
- [問題3] 競技者それぞれが前年より成長したのかどうか、不透明
  競技者向け記録管理アプリで、競技者の成長をサポート  
- [問題4] 当日の現場運営は本当に忙しく、なるべく効率化したい
  現場運営向けUIで、記録入力、ランキング更新、表示管理を効率化
